# Security Policy

## Supported Versions

Security updates are provided for the latest version of this repository.

| Version        | Supported |
| -------------- | :-------: |
| Latest         |     ✅     |
| Older versions |     ❌     |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public GitHub issue.

Instead, report it privately to the project maintainer through the contact information available on the GitHub profile.

Please include:

* A clear description of the vulnerability
* Steps to reproduce the issue
* Potential impact
* Suggested mitigation (if available)

All reports will be acknowledged as soon as possible and handled confidentially.

## Response Process

The project maintainer will:

1. Confirm receipt of the report.
2. Assess the severity and impact.
3. Develop and test a fix.
4. Release a patched version if necessary.
5. Credit the reporter where appropriate (unless anonymity is requested).

## Scope

This policy applies to:

* Source code
* Dependencies
* Configuration files
* GitHub Actions workflows
* Documentation-related security concerns

Thank you for helping keep this project secure.
