# Research Plan

## Title

Knowing When Not to Answer:
A Reliability-First Framework for Selective Question Answering

---

## Research Question

How can confidence calibration and evidence verification improve the reliability of large language models by allowing them to abstain from answering uncertain questions?

---

## Objectives

- Build a selective QA framework.
- Estimate model confidence.
- Improve confidence using calibration.
- Verify generated answers with external evidence.
- Design a decision engine.
- Evaluate reliability against baseline methods.

---

## Methodology

1. Dataset preparation
2. Baseline model
3. Confidence estimation
4. Confidence calibration
5. Evidence verification
6. Decision engine
7. Evaluation
8. Error analysis
