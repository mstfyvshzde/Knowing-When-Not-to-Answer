# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and inclusive environment for everyone who participates in this project.

All contributors, maintainers, and community members are expected to communicate professionally and treat others with respect.

## Expected Behaviour

Examples of positive behaviour include:

* Using respectful and inclusive language
* Accepting constructive feedback
* Focusing on ideas rather than individuals
* Showing empathy toward other community members
* Respecting different experiences and perspectives
* Supporting collaboration and open discussion

## Unacceptable Behaviour

Unacceptable behaviour includes:

* Harassment, discrimination, or personal attacks
* Insulting or degrading comments
* Publishing another person's private information
* Deliberate intimidation or disruption
* Repeatedly ignoring project guidelines
* Any conduct that creates an unsafe or hostile environment

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

Reports will be reviewed fairly and confidentially. Appropriate action may include a warning, removal of content, temporary restriction, or permanent exclusion from the project community.

## Reporting

To report unacceptable behaviour, contact the project maintainer privately through the contact information provided on the maintainer's GitHub profile.

Please include relevant details and evidence when possible.

## Scope

This Code of Conduct applies to all project spaces, including:

* Issues
* Pull requests
* Discussions
* Code reviews
* Project documentation
* Other public or private communication related to the project

## Attribution

This Code of Conduct is inspired by established open-source community standards and adapted for this project.
